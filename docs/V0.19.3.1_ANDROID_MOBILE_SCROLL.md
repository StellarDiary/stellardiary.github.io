# V0.19.3.1 — Android mobile viewport / scroll hardening

- Fixes the player-profile modal being scroll-safe only on iOS.
- Android Chrome now gets dynamic-viewport sizing and an independent vertical scroll area while body scrolling is locked.
- Prevents touch-first devices from auto-opening the software keyboard when the profile modal opens.
- Adds safe-area / dynamic-viewport caps to farm, train, mailbox, GM and GM-preview overlays.
- Adds `interactive-widget=resizes-content` to mobile viewport metadata for supporting Chromium browsers.
- No SQL migration is required.
