# V0.19.4.0 — 星辰季節盲盒

## 核心規則

- 新增「盲盒」商店分頁。
- 每個季節盲盒售價固定 **49 金幣**。
- 萬聖節盲盒開放期：10/1～11/30。
- 聖誕節盲盒開放期：12/1～1/15。
- 購買後進入背包；背包支援「單抽」與「十連抽」。
- 十連抽需要背包內至少 10 盒。
- 玩家已買下的季節盲盒即使活動期結束，仍可繼續開啟。

## 獎池

基礎獎池：

- 限定服裝：1%
- 永久寵物：1%
- 種子：55%
- 當期裝飾：18%
- 肥料：15%
- 再來一盒同款盲盒：10%

永久收藏去重：

- 萬聖盲盒的限定服裝為萬聖節造型；聖誕盲盒的限定服裝為聖誕造型。
- 寵物從目前已發布的永久寵物中隨機抽取一隻未擁有者。
- 玩家已擁有的服裝／寵物不會再次進入稀有獎池。
- 若某個 1% 稀有類別已無可抽的新收藏，該權重會重新分配到仍有效的獎池，不會抽到重複收藏再補償。
- 季節裝飾允許重複取得，因為同一裝飾可持有多件並擺放在不同位置。

## 手機操作

- 盲盒購買、單抽、十連抽按鈕使用 `touch-action: manipulation`。
- 同一時間只允許一筆盲盒操作；請求開始後立即鎖定按鈕。
- 額外攔截盲盒按鈕的 `dblclick`，避免手機快速連點觸發頁面放大。
- 沒有關閉整站的 pinch zoom，保留一般頁面的無障礙縮放能力。

## 雲端安全

盲盒不是前端 `Math.random()` 抽獎。

購買與開盒都由 Supabase RPC 在資料庫端完成：
- `buy_farm_blind_box_v1`
- `open_farm_blind_box_v1`

伺服器會在同一個 transaction / row lock 中處理：

1. 驗證登入玩家。
2. 驗證金幣或盲盒數量。
3. 扣除金幣／盲盒。
4. 執行抽獎。
5. 檢查永久收藏去重。
6. 發放種子、裝飾、肥料、盲盒、服裝或寵物。
7. 更新 `farm_saves` 與 revision。
8. 將更新後 state 回傳前端。

因此快速連點、重新整理、跨裝置同時操作時，不會只靠瀏覽器狀態結算。
