# V0.19.5.1 — 新手教學 UI／手機版修正

## 修正內容
- 歡迎頁與完成頁不再顯示品牌佔位圖，也不顯示「點擊圖片可放大查看」。
- 只有 Step 1～6 的實際教學截圖頁才建立圖片顯示區。
- 增加教學內部 `hidden` 元件的強制隱藏規則，避免 CSS 的 `display` 覆蓋 HTML hidden 狀態。
- 桌機：無圖片頁切換為置中單欄；圖片頁維持雙欄。
- 手機：縮減 header、圖片區、說明與 footer 的垂直佔用，圖片完整 contain，不裁切，並保留點圖放大與左右滑動。

## 語言
- 預設简体中文。
- 繁體中文／English 的教學文字繼續同步切換。
- 目前教學截圖仍使用简体中文版本，未來可直接增加 `zh-TW`／`en` 對應圖片。
