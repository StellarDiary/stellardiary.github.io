# V0.19.7.0 — 塔罗解读 2.0

## 目标

本版不追求单纯“把文字写长”，而是让塔罗结果更接近真人读牌：先回答玩家真正问的问题，再解释牌位、牌与牌之间的关系，以及可以带回现实的下一步。

## 主要变化

1. **问题意图拆解**：同一题可同时识别感受、原因、主动联系、复合、时间、发展、二选一、建议等多个意图，并分别回答。
2. **每张牌更有个性**：大阿尔克那加入独立原型层；小阿尔克那结合花色与数字／宫廷阶段，不再只套用同一花色的一句说明。
3. **牌位真正参与解读**：同一张牌落在现况、阻碍、建议、对方、方向等位置时，会用不同角度说明它在这次问题里的角色。
4. **组合叙事**：多张牌会分析相邻关系、元素支持／冲突、正逆位节奏及牌势变化；关系、周运、月运与二选一牌阵各自使用不同叙事结构。
5. **证据化直接回答**：结论会指出哪些牌位／牌面支持判断，减少只有抽象结论却看不出依据的情况。
6. **现实检核**：第三者、承诺、工作转换、面试、投资、债务、考试等高不确定问题会明确区分塔罗提示与现实证据。
7. **具体下一步**：最终建议结合引导牌、主要阻碍与问题场景，给出更可执行的观察或行动方向。
8. **降低模板重复**：连接句与总结导语使用稳定的多版本表达；同一次结果不会因重载而任意改口，但不同牌组不再总出现同一句。

## 保留项目

- V0.19.6.0 的系统自动翻牌完整保留。
- 78 张 RWS 系牌库、正逆位与既有牌阵保持兼容。
- 历史记录格式保持兼容。
- 不需要 Supabase migration。

## 三语系

默认简体中文，同时保留繁體中文与 English；新增的直接回答、组合关系、情境提示与最终建议皆提供三语文案。
