# V0.19.9.0 — 每日解签 2.0

## 本版目标

把原本「抽到一支签后，快速看几个分类句子」升级成更接近真人解签的完整阅读体验。60 支签、六十甲子、每日一签与当地时间 00:00 重置规则全部保留，本版只深化解签内容与呈现结构。

## 主要升级

1. **今日签意**
   - 保留原本简短总览，再增加一层完整解释。
   - 不只说吉凶，会说明今天真正的节奏、为什么这样判断，以及这支签适合怎么使用。
   - 明确提醒：签意是观察角度，不是把现实结果写死。

2. **签诗解读**
   - 四句签诗不再只是展示。
   - 新增前两句／后两句之间的转折说明，把景象、处境与行动方向串成完整意思。
   - 避免只抓单句判断吉凶。

3. **今日可能出现的讯号**
   - 每支签新增 3 个生活化观察点。
   - 可能来自讯息、互动、工作进度、身体状态、数字或环境变化。
   - UI 明确说明「没有出现也不用刻意寻找」，避免玩家为了应验而过度联想。

4. **四大领域深度解读**
   - 感情、事业／学业、财运、人际全部扩写。
   - 感情会多看持续行动、实际投入、边界与沟通，不只看一句话或一次回复。
   - 工作／学业会落到完成、确认、交付、优先级、卡点原因与可验证进展。
   - 财运会回到预算、现金流、风险、总成本与可承受范围。
   - 人际会强调双向、直接确认、责任边界与真实互动质量。

5. **今天适合做／今天最好避免**
   - 每支签各有一个明确行动与一个需要避开的模式。
   - 让解签最后能落回今天真正可以执行的选择。

6. **留给今天的一句话**
   - 每支签新增独立收尾，不再只是重复「今日提醒」。
   - 用一句较有人味的总结，把整支签收回核心。

7. **降低重复感**
   - 60 支签各自保留独立核心主题。
   - 今日签意、签诗结语、四大领域收尾使用多组稳定表达，而不是全部以同一句模板结束。
   - 同一支签每天重看内容保持稳定，不做每次刷新随机换句。

## 旧记录兼容

- 每日签历史 snapshot 升级为 `snapshotVersion: 2`。
- 若玩家今天是在 V0.19.8.0 或更早版本已经抽过签，更新后仍然保持**同一支签**，不会重新抽。
- 前端会把旧 snapshot 与新版同 ID 的标准签文合并，让当天旧签也能显示新的深度解读。

## 推播

Bark 继续使用原本较短的摘要，不把完整长篇解签全部塞进推播，避免通知过长；网站内保留完整解签。

## 数据库

本版没有 Supabase schema 变更，**不需要执行新的 SQL migration**。
