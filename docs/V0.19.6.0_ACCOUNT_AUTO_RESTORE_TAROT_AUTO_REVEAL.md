# V0.19.6.0 — 帳號自動恢復 / 塔羅自動翻牌

## 1. 帳號登入／恢復流程

先前玩家在新裝置登入既有正式會員後，會看到「使用原帳號雲端資料（推薦）」與「合併這台裝置的遊客資料」兩個選項。

V0.19.6.0 起取消此選擇頁：

1. 玩家完成既有帳號 Email 驗證。
2. 系統切換到原本正式會員身份。
3. 自動執行原本的推薦方案 `cloud`。
4. 以原帳號雲端資料恢復本機的個人資料、本命盤、合盤、每日運勢與塔羅歷史。
5. 成功後清除登入／恢復暫存狀態。

為避免登入切換期間把臨時遊客資料反向同步到正式帳號，恢復完成前仍保留 restore guard；只是 UI 不再要求玩家選擇。若網路造成恢復失敗，保留 pending 狀態並可由「立即同步資料」重試原本的推薦恢復方案。

## 2. 塔羅牌自動翻牌

- 玩家仍維持原流程：輸入問題 → 選擇問題方向 → 選擇牌陣 → 點擊牌堆開始抽盤。
- 抽牌完成後，牌背全部不可點擊。
- 系統依牌位順序自動執行翻牌動畫。
- 一張揭曉完成後再進入下一張；單張、三張、五張共用同一流程。
- 自動揭牌期間暫時鎖定「開始抽盤／重新抽盤」，防止同一牌陣被重複觸發。
- 最後一張完成後解除鎖定，顯示原有完整組合解讀、保存塔羅歷史並執行既有 Bark 摘要。
- `prefers-reduced-motion` 使用較短等待時間，避免需要減少動畫的裝置仍被迫等待完整動畫節奏。
