# V0.20.0 — 星辰资源更新系统 1.0

## 目标
随着塔罗牌、农场角色、宠物、季节装饰与活动图片持续增加，避免每个版本都让玩家重复下载全部图片，同时解决浏览器仍使用旧 JS／CSS／图片快取的问题。

## 玩家流程
1. 打开任何星辰日记页面。
2. 系统先检查最新版本与资源清单。
3. 第一次使用：显示「正在准备星辰日记」，下载核心资源与当前页面必要资源。
4. 已安装且没有更新：检查完成后直接进入，不显示长时间更新流程。
5. 有新版本：显示旧版 → 新版、更新内容、文件数量、容量与百分比。
6. 必要资源全部完成后才切换版本；版本更新完成会自动重新载入。
7. 下载失败时保持更新画面，提供重新更新，不让半套新旧资源直接进入网站。

## 缓存策略
- `version.json`：服务器最新版本与三语更新说明。
- `asset-manifest.json`：资源 hash、bytes 与资源群组。
- `service-worker.js`：网站请求缓存与离线后备。
- `js/update-manager.js`：版本检查、进度、增量复制与版本切换。
- `css/update-manager.css`：更新遮罩与手机／桌面版 UI。

### 核心资源
HTML、CSS、JavaScript、JSON 数据属于 shell。升级时会先确保这些资源一致，避免新 HTML 搭配旧 JS。

### 当前页面资源
首页、账号、每日运势、塔罗、本命盘、合盘、农场分别有自己的必要资源组。只有玩家进入该页面时才准备该组。

### 大型图片
78 张塔罗牌面、季节服装、宠物 Sprite、部分季节活动资源不要求第一次进入首页时全部下载。第一次真正使用时由 Service Worker 缓存，避免网站总体积持续增加后拖慢所有玩家。

## 增量更新
每个资源在 manifest 中记录 SHA-256 摘要。新版本更新时：
- hash 未变化且上一版本缓存存在：复制旧缓存，不重新走网络下载。
- hash 改变／新增资源：下载新版。
- 更新完成后保留当前版本与上一版本缓存；更旧缓存会清理。

## 安全边界
资源更新系统只管理静态网站文件，不删除或重置：
- Supabase Auth 登录状态
- 云端记录
- 星辰农场存档
- 玩家资料
- localStorage 内的功能偏好（资源版本标记除外）

## V0.20.0 首次资源量（约）
- 核心 shell：约 2.3 MB
- 首页额外资源：约 2.2 MB
- 塔罗页面额外核心：约 0.5 MB（78 张牌面仍按需缓存）
- 农场页面核心：约 9 MB；季节装饰、宠物与非当前必要动画按需缓存

## 数据库
本版无 Supabase schema 变更，不需要 SQL migration。
